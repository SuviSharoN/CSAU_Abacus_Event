ABACUS'26 COLLABORATIVE BUILD CHALLENGE

Setup Instructions
------------------

1. Extract the zip folder.
2. Open the extracted folder in VS Code.
3. Start Live Server on `feature-templates/index.html`.
4. Open your assigned feature folder and complete TODO sections.

Available Features (Current)
----------------------------

1. EVENTS
   Folder: `events/`
   Main focus: Event cards render + grid styling task.

2. WORKSHOPS
   Folder: `workshops/`
   Main focus: Add Previous/Next buttons (HTML), complete cyclic button JS, and button alignment CSS.

3. ACCOMMODATION
   Folder: `accommodation/`
   Main focus: Build room registration flow from TODOs.

4. PROFILE
   Folder: `profile/`
   Main focus: Build and style profile form + basic form validation behavior.

5. LOGOUT
   Folder: `logout/`
   Main focus: Basic confirm logout flow task.

Tips
