📚 ABACUS'26 COLLABORATIVE BUILD CHALLENGE

Setup Instructions:
-------------------

1. Extract the zip folder

2. Open the folder in VS Code
   - Open VS Code
   - File → Open Folder → Select the extracted folder

3. Start Live Server
   - Right-click on index.html (in feature-templates/)
   - Select "Open with Live Server"
   - Browser opens automatically → localhost:5500/

4. You're ready!
   - Click on your assigned feature
   - Open the files in VS Code
   - Fill in the blanks marked "TODO: CODE THIS"
   - Save file → Refresh browser to see changes
